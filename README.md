A fast static site generator: Markdown files in, a complete static site out. It renders pages, collections, tags, indexes and pagination with a hand-written single-pass Markdown renderer and templates compiled to plain JavaScript, so a site of several hundred pages builds in about a tenth of a second per case on the practice set — roughly 3× faster than the reference implementation, byte-for-byte identical output.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
